# Context folder

This folder is not part of the published site — it's just for keeping a record of the
conversations/decisions behind changes made to this project.

Paste chat conversations into dated text files here, e.g.:
- 2026-07-30-footer-and-about-section.txt
- 2026-08-05-training-section.txt

Keeping this alongside the code means anyone picking up the project later can see
*why* something was built a certain way, not just what the code does.
